### 任务 2：模块划分与技术选型（2 小时）

#### 2.1 模块划分
##模块划分
1. 系统基础支撑模块
职责边界
- 全局统一异常处理、全局返回封装
- 登录认证、JWT令牌、权限拦截、角色权限控制
- 校园实名认证、学生学号/学院信息校验
- 全局字典、常量、通用工具类、分页封装
- 接口限流、跨域配置、全局配置参数
依赖：无外部业务依赖，为所有模块提供基础支撑
2. 用户中心模块
职责边界
- 用户注册、登录、个人信息管理
- 校园身份认证、头像/资料编辑
- 信用分体系：信用分计算、奖惩记录、信用分查询
- 用户标签管理（学业型、跑腿型、二手交易型、组队型等标签）
依赖：依赖系统基础支撑模块
3. 需求发布与订单模块
职责边界
- 各类需求发布：快递代取、学习辅导、二手求购/出售、活动组队、校园跑腿
- 需求状态流转：待匹配、已接单、进行中、已完成、取消
- 互助订单创建、订单生命周期管理
- 需求列表、筛选、收藏、我的发布/我的接单
依赖：依赖 系统基础支撑模块，用户中心模块
4. 智能匹配引擎模块
职责边界
- 实现规则匹配引擎：用户标签匹配 + 校园位置距离匹配 + 信用分门槛筛选
- 接收用户需求，自动推荐合适接单者
- 匹配规则配置、权重配置（标签权重/距离权重/信用权重）
- 匹配结果缓存至 Redis
依赖：依赖 系统基础支撑模块，用户中心模块 ，需求发布与订单模块，Redis
5. 二手物品交易模块
职责边界
- 二手商品发布、分类管理、商品上下架
- 商品详情、留言咨询、交易意向沟通
- 二手商品类目、违规信息初步过滤
依赖：依赖 用户中心模块、需求发布与订单模块、系统基础支撑模块
6. 评价与投诉模块
职责边界
- 互助完成后双向评价、星级评分
- 评价记录归档、口碑展示
- 投诉提交、管理员审核处理、违规用户标记
- 评价数据同步更新用户信用分
依赖：依赖 用户中心模块、需求发布与订单模块、系统基础支撑模块
7. 消息通知模块
职责边界
- 系统消息、订单状态通知、匹配成功通知、评价提醒
- 小程序订阅消息、站内信
- 消息列表、已读/未读状态管理
- Redis 做消息临时缓存
依赖：依赖所有业务模块、系统基础支撑模块、Redis
8. 管理后台模块
职责边界
- 后台管理员账号、权限菜单管理
- 全校数据统计：发布量、成交量、活跃用户、交易热度
- 内容审核：违规需求、违规商品、违规用户封禁
- 平台规则配置、匹配参数后台配置
依赖：依赖 所有模块

##接口
1. 调用方式
因为是模块化分层单体，不拆微服务：
- 模块之间采用Spring 本地 Bean 注入 Service 接口调用
- 不使用 Feign、HTTP、MQ 远程调用，同进程内本地方法调用
- 仅前后端之间用 RESTful HTTP 接口交互

2. 统一返回数据格式（所有对外接口统一）
{
  "code": 200,
  "msg": "操作成功",
  "data": {},
  "timestamp": 1712345678901
}
- 成功码：200
- 业务失败：4xx
- 系统异常：5xx
